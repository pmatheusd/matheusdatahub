# Portfólio de Matheus Oliveira

Site estático em um único arquivo (`index.html`), sem dependências nem etapa de build.

## Onde editar

| O que mudar | Onde fica no `index.html` |
|---|---|
| Cores e fonte | Bloco `:root` no início do `<style>` (versões clara e escura) |
| Texto de abertura | Comentário `ABERTURA` |
| Estudos de caso | Comentário `ESTUDOS DE CASO` (há um modelo comentado para copiar) |
| Trajetória (gráfico) | Lista `trajetoria` no `<script>` no fim do arquivo |
| Competências, formação e contato | Comentários com o nome de cada seção |
| Currículo para download | Coloque `curriculo.pdf` nesta pasta e ative o link na seção `CONTATO` |

## Publicação

Hospedado no GitHub Pages. Cada alteração enviada à branch `main` atualiza o site em cerca de um minuto.

## Cuidados

Não publicar dados confidenciais de empresas (faturamento, clientes, metas) nem dados pessoais sensíveis.
